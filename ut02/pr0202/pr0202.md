2.	Carga de datasets
o	Descarga el dataset Automotive Price Prediction Dataset que puedes obtener desde Kaggle y que contiene un dataset sintético con información y precio de 1000000 de vehículos de segunda mano
 
Ruta local Windows: "C:\Users\abdpa\Downloads\vehicle_price_prediction.csv"
 
o	Desde tu sistema local, sube al directorio proyecto_datos el dataset que has descargado.
1º.- Mover de local (windows) a Docker :

* docker cp "C:\Users\abdpa\Downloads\vehicle_price_prediction.csv" namenode:/root

Primeras líneas:

2º.- Mover de Docker a HDFS:

* hdfs dfs -put ./vehicle_price_prediction.csv /user/hadoop/proyecto_datos

4.	Organización del proyecto
o	Crea un subdirectorio procesados y otro backup dentro de tu carpeta de proyecto

* hdfs dfs -mkdir -p /user/hadoop/proyecto_datos/

procesados
* hdfs dfs -mkdir -p /user/hadoop/proyecto_datos/backup

Primeras líneas: no muestra nada.

o	Copia el archivo original a backup.

* hdfs dfs -put ./vehicle_price_prediction.csv /user/hadoop/proyecto_datos/backup

Primeras líneas: no muestra nada.

o	Mueve el archivo original de proyecto_datos a procesados.

* hdfs dfs -mv /user/hadoop/proyecto_datos/vehicle_price_prediction.csv /user/hadoop/proyecto_datos/procesados/

Primeras líneas: no muestra nada.

5.	Colaboración en el equipo
o	Crea un directorio compartido bajo /compartido (si no existe) y copia allí tu dataset para que otros puedan acceder.

Crear directorio:
* hdfs dfs -mkdir -p /user/hadoop/proyecto_datos/compartido

Primeras líneas:
Verifico con: hdfs dfs -ls /user/hadoop/proyecto_datos/compartido
Found 1 items
-rw-r--r--   3 root supergroup  126967327 2026-10-29 19:52 /user/hadoop/proyecto_datos/compartido/vehicle_price_prediction.csv

Asignarle permisos de lectura y ejecución y escritura para otros usuarios:

* hdfs dfs -chmod 755 /user/hadoop/proyecto_datos/compartido

Copiar allí tu dataset:
* hdfs dfs -put ./vehicle_price_prediction.csv /user/hadoop/proyecto_datos/compartido
