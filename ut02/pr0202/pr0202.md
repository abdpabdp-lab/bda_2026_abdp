# Práctica - PR0202 - Uso del cliente HDFS (1):

* [Solución PR0202: ]

1.	Preparación del entorno
o	Crea un directorio personal en HDFS bajo /user con tu nombre de usuario y dentro de él un directorio llamado proyecto_datos.


hdfs dfs -mkdir -p /user/hadoop/proyecto_datos
 

2.	Carga de datasets
o	Descarga el dataset Automotive Price Prediction Dataset que puedes obtener desde Kaggle y que contiene un dataset sintético con información y precio de 1000000 de vehículos de segunda mano
 
Ruta local Windows: "C:\Users\abdpa\Downloads\vehicle_price_prediction.csv"
 
o	Desde tu sistema local, sube al directorio proyecto_datos el dataset que has descargado.
1º.- Mover de local (windows) a Docker :

docker cp "C:\Users\abdpa\Downloads\vehicle_price_prediction.csv" namenode:/root
 

2º.- Mover de Docker a HDFS:

hdfs dfs -put ./vehicle_price_prediction.csv /user/hadoop/proyecto_datos
 
3.	Exploración de datos
o	Visualiza el contenido del archivo directamente en HDFS.

hdfs dfs -cat /user/hadoop/proyecto_datos/vehicle_price_prediction.csv
o	Obtén el número de líneas del dataset.

hdfs dfs -cat /user/hadoop/proyecto_datos/vehicle_price_prediction.csv | wc -l

Resultado:1000001


4.	Organización del proyecto
o	Crea un subdirectorio procesados y otro backup dentro de tu carpeta de proyecto

hdfs dfs -mkdir -p /user/hadoop/proyecto_datos/

procesados
hdfs dfs -mkdir -p /user/hadoop/proyecto_datos/backup

o	Copia el archivo original a backup.

hdfs dfs -put ./vehicle_price_prediction.csv /user/hadoop/proyecto_datos/backup

o	Mueve el archivo original de proyecto_datos a procesados.

hdfs dfs -mv /user/hadoop/proyecto_datos/vehicle_price_prediction.csv /user/hadoop/proyecto_datos/procesados/

5.	Colaboración en el equipo
o	Crea un directorio compartido bajo /compartido (si no existe) y copia allí tu dataset para que otros puedan acceder.

Crear directorio:

 hdfs dfs -mkdir -p /user/hadoop/proyecto_datos/compartido

Asignarle permisos de lectura y ejecución y escritura para otros usuarios:

hdfs dfs -chmod 755 /user/hadoop/proyecto_datos/compartido

Copiar allí tu dataset:
hdfs dfs -put ./vehicle_price_prediction.csv /user/hadoop/proyecto_datos/compartido

6.	Recuperación de datos
o	Descarga a tu sistema local el archivo que está en el directorio procesados.

1º.-Mover de HDFS (/user/hadoop/proyecto_datos/procesados) a Docker:
hdfs dfs -get /user/hadoop/proyecto_datos/ompartido/vehicle_price_prediction.csv ./vehicle_price_prediction.csv
 
2º.-Mover de Docker a local:
docker cp namenode:/root/vehicle_price_prediction.csv C:\Users\abdpa\OneDrive\Desktop\Curso_IA\BDA_5074\ficheros_tareas"

7.	Control de accesos
o	Verifica los permisos de tus archivos.
hdfs dfs -ls /user/hadoop/proyecto_datos/backup
hdfs dfs -ls /user/hadoop/proyecto_datos/compartido
hdfs dfs -ls /user/hadoop/proyecto_datos/procesados

Tiene el permiso -rw-r--r-- 


o	Cambia los permisos de un archivo de backup para que solo tú tengas acceso de lectura y escritura.

hdfs dfs -chmod 600 /user/hadoop/proyecto_datos/backup/vehicle_price_prediction.csv

8.	Mantenimiento
o	Elimina un archivo temporal que hayas subido por error a tu espacio en HDFS.

1º.- Mover de local (windows) a Docker :

docker cp "C:\Users\abdpa\OneDrive\Desktop\Curso_IA\BDA_5074\ficheros_tareas\~DFFF5B8A2B9E9582E7.TMP" namenode:/root

2º.- Mover de Docker a HDFS:

hdfs dfs -put ./~DFFF5B8A2B9E9582E7.TMP /user/hadoop/proyecto_datos

3º.- Eliminar el archivo temporal (~DFFF5B8A2B9E9582E7.TMP) que está en HDFS:

hdfs dfs -rm  /user/hadoop/proyecto_datos/~DFFF5B8A2B9E9582E7.TMP
