# Práctica - PR0203 - Uso del cliente HDFS (2) (opcional):

* [Solución PR0203: ]

1.	Preparación el espacio de trabajo en HDFS
o	Crea un directorio principal /proyectos/ecommerce en HDFS.

* hdfs dfs -mkdir -p /user/hadoop/proyectos/ecommerce

o	Dentro de él, crea tres subdirectorios:
	/raw → para los logs originales.
	/procesados → para los logs ya tratados.
	/backup → para copias de seguridad.


* hdfs dfs -mkdir -p /user/hadoop/proyectos/ecommerce/raw
* hdfs dfs -mkdir -p /user/hadoop/proyectos/ecommerce/procesados
* hdfs dfs -mkdir -p /user/hadoop/proyectos/ecommerce/backup
